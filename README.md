# Title
#### Payoo – Digital Wallet Simulation

## Description
__Payoo App__ is a responsive frontend web application that simulates a digital payment and balance management system. The project focuses on creating an interactive user interface where users can manage transactions such as adding money, cashing out, and transferring funds in a clean and intuitive dashboard.

The interface dynamically updates the user balance and transaction history using JavaScript DOM manipulation, allowing users to interact with the system without page reloads. The goal of this project is to demonstrate practical skills in event handling, UI state updates, and building interactive web applications.

The concept is inspired by modern digital wallet systems that allow users to manage payments and bills digitally, similar to real-world e-wallet platforms that handle various financial transactions and services.

## Feature
- Add money to account balance
- Cash out functionality
- Transfer money between users
- Dynamic balance updates
- Transaction history tracking
- Interactive UI with modal forms
- Responsive design for different devices

## Technologies Used
- HTML5
- Tailwind CSS
- JavaScript (ES6+)
- DOM Manipulation
- Event Handling
