# Title
#### Expense Tracker (DOM Project)

## Description
A dynamic expense tracking app built using JavaScript DOM manipulation. Users can add, delete, and manage transactions with real-time balance updates.

## Feature
- Add/delete transactions
- Real-time balance calculation
- Local storage persistence
- Responsive UI

## Tech stack
- HTML
- CSS
- JavaScript (DOM)
